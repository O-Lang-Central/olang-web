Deploy / Channels

Connect O-Lang to
any channel

O-Lang is governed AI infrastructure — not a chatbot platform. It exposes a single /run endpoint. You own the channel. These guides show you how to wire them together.

O-Lang's role is the runtime. Every message your users send — whether on WhatsApp, Telegram, or your own website — passes through the O-Lang kernel, gets vector-searched against your documents, runs through your governed chain, and returns a cryptographically signed, PII-masked response. The channel is your responsibility. The governance is ours.

Universal Integration Pattern
Channel (WhatsApp / Telegram / etc.)
→
message arrives
│
Your webhook handler
→
extract text, identify user
│
POST /run → O-Lang kernel
→
RAG + governance + audit signing
│
Your reply handler
→
send governed response back
│
User receives answer
→
with full audit trail in your dashboard

WhatsApp
Meta Cloud API · 3 billion users · No SDK required
Free API
ℹ️
Meta's Cloud API is free to use. You only pay Meta's conversation fees (~$0.01–0.05 per 24hr window). Since July 2025, service conversations (customer-initiated) are completely free. No Twilio. No middleware. Direct to Meta.
01
Create a Meta Developer App
Go to developers.facebook.com → My Apps → Create App. Choose Business as the type. Add the WhatsApp product. This creates your WhatsApp Business Account (WABA) automatically.
💡
Meta provides a free test phone number for development. Use it to test your integration before connecting a real business number.
02
Generate a permanent access token
In Business Settings → Users → System Users → Add. Name it anything, role: Admin. Click Generate Token, select your app, grant whatsapp_business_messaging and whatsapp_business_management permissions. This token never expires.
⚠️
The token shown in the API Setup panel is temporary (expires in hours). Always use a System User token in production.
03
Set your webhook URL
In your Meta app → WhatsApp → Configuration → Edit. Set the Callback URL to your server and choose a Verify Token (any string you decide — store it as an env var). Subscribe to the messages field.
Callback URL
https://your-server.com/webhook/whatsapp
04
Add environment variables
Variable Description Where to find it
META_APP_SECRET Signs webhook payloads — verifies requests are genuinely from Meta App Settings → Basic
META_VERIFY_TOKEN Your chosen string — must match what you entered in Meta dashboard You choose this
META_ACCESS_TOKEN System user permanent token for sending messages System Users → Generate Token
META_PHONE_NUMBER_ID Identifies which business number to send from WhatsApp → API Setup
OLANG_API_KEY Your O-Lang cloud API key olang.cloud → Dashboard
05
Add the webhook handler to your server
Copy this into your Node.js server. It handles webhook verification, parses incoming messages, calls O-Lang, and sends the reply back to Meta.
JavaScript · Node.js
import express from 'express'; import crypto from 'crypto'; const app = express(); app.use(express.json()); // ── Verify webhook (GET) — Meta calls this once on setup ── app.get('/webhook/whatsapp', (req, res) => { const mode = req.query['hub.mode']; const token = req.query['hub.verify_token']; const challenge = req.query['hub.challenge']; if (mode === 'subscribe' && token === process.env.META_VERIFY_TOKEN) { return res.send(challenge); // must return as plain text } res.sendStatus(403); }); // ── Receive messages (POST) ────────────────────────────── app.post('/webhook/whatsapp', async (req, res) => { res.sendStatus(200); // respond immediately — Meta retries otherwise const change = req.body?.entry?.[0]?.changes?.[0]?.value; const message = change?.messages?.[0]; if (!message || message.type !== 'text') return; const from = message.from; const phoneNumberId = change.metadata.phone_number_id; const userText = message.text.body; // ── Call O-Lang ────────────────────────────────────────── const olangRes = await fetch('https://api.olang.cloud/run', { method: 'POST', headers: { 'Content-Type': 'application/json', 'x-api-key': process.env.OLANG_API_KEY, }, body: JSON.stringify({ workflow: 'customer-support-rag', input: { query: userText, userId: from }, }), }); const { reply } = await olangRes.json(); // ── Send reply back via Meta Graph API ─────────────────── await fetch(`https://graph.facebook.com/v21.0/${phoneNumberId}/messages`, { method: 'POST', headers: { 'Authorization': `Bearer ${process.env.META_ACCESS_TOKEN}`, 'Content-Type': 'application/json', }, body: JSON.stringify({ messaging_product: 'whatsapp', to: from, type: 'text', text: { body: reply.response }, }), }); });
🚀
That's the complete integration — under 50 lines. O-Lang handles the RAG, governance, PII masking, and audit trail. You handle the WhatsApp channel. Full working example on GitHub →

Telegram
Bot API · 900 million users · Completely free · No approval needed
Completely Free
ℹ️
Telegram's Bot API is completely free with no conversation fees, no approval process, and no business verification required. You can have a bot running in under 5 minutes. Ideal for internal tools, developer communities, and early testing.
01
Create a bot with BotFather
Open Telegram and search for @BotFather. Send /newbot, choose a name and username (must end in bot). BotFather returns your Bot Token — save it.

02
Add environment variables
VariableDescriptionWhere to find it
TELEGRAM_BOT_TOKEN Authenticates your bot with Telegram's API BotFather → /newbot
TELEGRAM_WEBHOOK_SECRET Random string — verifies requests are from Telegram You choose this
OLANG_API_KEY Your O-Lang cloud API key olang.cloud → Dashboard
03
Register your webhook with Telegram
Run this once after deploying your server. Telegram will POST every message to your URL from this point on.
Shell · one-time setup
curl -X POST \ https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/setWebhook \ -H "Content-Type: application/json" \ -d '{ "url": "https://your-server.com/webhook/telegram", "secret_token": "'${TELEGRAM_WEBHOOK_SECRET}'" }' # Expected response: # {"ok":true,"result":true,"description":"Webhook was set"}
04
Add the webhook handler to your server
JavaScript · Node.js
// ── Receive messages from Telegram ────────────────────── app.post('/webhook/telegram', async (req, res) => { // Verify request is genuinely from Telegram const secret = req.headers['x-telegram-bot-api-secret-token']; if (secret !== process.env.TELEGRAM_WEBHOOK_SECRET) { return res.sendStatus(403); } res.sendStatus(200); // respond immediately const msg = req.body?.message; if (!msg?.text) return; // ignore non-text (photos, stickers, etc.) const chatId = msg.chat.id; const userId = String(msg.from.id); const userText = msg.text; // ── Call O-Lang ────────────────────────────────────────── const olangRes = await fetch('https://api.olang.cloud/run', { method: 'POST', headers: { 'Content-Type': 'application/json', 'x-api-key': process.env.OLANG_API_KEY, }, body: JSON.stringify({ workflow: 'customer-support-rag', input: { query: userText, userId }, }), }); const { reply } = await olangRes.json(); // ── Send reply back via Telegram Bot API ───────────────── await fetch( `https://api.telegram.org/bot${process.env.TELEGRAM_BOT_TOKEN}/sendMessage`, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ chat_id: chatId, text: reply.response, parse_mode: 'Markdown', // O-Lang returns clean markdown }), } ); });
🚀
Telegram is the fastest channel to test with — no approval, no fees, live in minutes. Use it to validate your O-Lang workflow before deploying to WhatsApp. Full working example on GitHub →
